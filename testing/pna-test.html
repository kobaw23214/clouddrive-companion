检测前请确认

1. 本机已运行「网盘伴侣」客户端（或测试探测端点已开启）。
2. 用浏览器新标签页直接打开 http://localhost:34567/pna-probe ，能看到一段 JSON 即说明探测端点正常（这是 loopback→loopback，永不被拦）。
3. 回到本页面（必须是通过公网/局域网 IP 打开的），点击「一键检测」。
若第 2 步打不开，请先解决端点未启动问题，否则检测会误判为「被拦截」。
